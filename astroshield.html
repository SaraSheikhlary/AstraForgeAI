AstroShield AI

AstroShield AI is a high-performance, self-contained Digital Twin platform for Space Traffic Management (STM). It processes real-time TLE telemetry for active orbital populations across Low Earth Orbit (LEO), utilizing advanced spatial algorithms and decoupled containerized pipelines to predict kinetic collision risks, inspect individual satellite telemetry, and safeguard critical space infrastructure.

Key Features & Technical Architecture

  • Spatial Physics Engine: Replaced brute-force proximity checks with a compiled KD-Tree spatial indexing algorithm (`cKDTree` via SciPy)[cite: 2]. This allows for sub-3 millisecond conjunction analysis across 15,000+ orbital nodes by utilizing multi-dimensional binary search trees[cite: 2].
  • Self-Contained Cloud Architecture: Engineered a high-performance, self-contained Streamlit Cloud architecture that eliminates external backend spin-down latencies, ensuring instantaneous UI responsiveness, persistent 24/7 operational availability, and zero cold-start delay.
  • Granular Asset Telemetry Inspector: Features an interactive target satellite inspection module enabling operators to query individual catalog assets on-demand, analyzing real-time state vectors, local position-velocity covariance (RIC), available $\Delta v$ propellant safety margins, and autonomous readiness[cite: 2].
  • High-Fidelity 3D Situational Awareness: Developed a hardware-accelerated 3D WebGL environment that automatically categorizes and renders orbital shells and active satellite populations, implementing tactical color-filtering to differentiate lethal debris from active assets in real time[cite: 2].
  • Engineering-Grade Evasion Analytics: Built an autonomous maneuver module that calculates specific mission metrics, including Required Delta-V, Burn Vectors, Propellant Mass Cost (kg), and NASA/CARA-aligned collision probability ($P_c$) reduction down to negligible safety thresholds (e.g., $6.23 \times 10^{-24}$)[cite: 2].
  • SGP4 Physics & Uncertainty Integration: Leveraged rigorous SGP4 analytical propagation and dual-covariance B-plane projections (validated via Monte Carlo ensemble analysis, $W = 0.9995$) to account for ephemeris uncertainties and generate precise UTC state vectors[cite: 2].
